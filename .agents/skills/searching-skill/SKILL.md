# Searching Skill

Guidelines and sources for finding tech events.

## Tech Events

When asked to find tech events:
- Search in [Geektime](https://www.geektime.co.il/) (`https://www.geektime.co.il/`).
- Execute search queries targeted at Geektime (e.g. `site:geektime.co.il` or searching Geektime tech event listings) to discover upcoming events, meetups, and conferences.
- Ensure the extracted item links are from Geektime and set the website to `geektime.co.il`.
